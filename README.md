# DragonAgeToolset

Backup of BioWare's Dragon Age Toolset resources and the recovered Dragon Age Toolset Wiki.

The wiki export lives in [`Wiki/`](Wiki/).

The full-width GitHub Pages build is generated from that export by [`scripts/build_pages_site.py`](scripts/build_pages_site.py) and deployed by [`.github/workflows/pages.yml`](.github/workflows/pages.yml).

Once GitHub Pages is enabled with **Source: GitHub Actions**, the site will publish to:

https://adarec1994.github.io/DragonAgeToolset/
